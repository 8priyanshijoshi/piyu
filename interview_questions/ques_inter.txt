React applies minimum changes to the Real DOM for better performance.

39. What is Lifting State Up in React?
Lifting state up moves state from child to parent for better data sharing. Example:

jsx

}

function Child({ count, onIncrement }) {
  return <button onClick={onIncrement}>Count: {count}</button>;
}
Parent manages state instead of each child, ensuring better control.

61. What are error boundaries in React v16?
Error boundaries catch errors inside components to prevent app crashes. Example:

jsx
class ErrorBoundary extends React.Component {
  constructor() {
    super();
    this.state = { hasError: false };
  }
  static getDerivedStateFromError() {
    return { hasError: true };
  }
  render() {
    return this.state.hasError ? <h1>Error occurred!</h1> : this.props.children;
  }
}

React v15 did not have error boundaries, and errors could crash the whole application. Developers relied on try...catch inside lifecycle methods.
